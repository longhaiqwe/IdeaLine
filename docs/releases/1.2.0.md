# 灵感晾台 1.2.0

支持 macOS 14+、Apple Silicon 和 Intel。正式 ZIP 安装包使用 Developer ID 签名并通过 Apple 公证。下载 `IdeaLine-v1.2.0-macOS-universal.zip`，解压后将「灵感晾台.app」拖入「应用程序」并打开；无需安装开发工具。

- 新增四个晾台方位：菜单栏 → 晾台位置 → 上方 / 下方 / 左侧 / 右侧，重启后保留选择。
- 左右侧以竖排展示全部便签，可用鼠标滚轮或触控板连续滚动，便签之间的空隙也能接收滚动。
- 根据所选方位沿横向或纵向拖动便签排序，便签文字始终正向显示。
- 上下方保留横向分页；侧边工具栏保持可见，便于新建和查看全部选题。

1.1.0 用户可在菜单栏点击「检查更新…」升级。选题、草稿、收纳和排序继续保存在本机。

自行构建请按仓库 README 的步骤操作；GitHub 自动生成的 Source code 压缩包是源码，直接使用请选择上述应用 ZIP。`SHA256SUMS.txt` 提供安装包的 SHA-256 校验值。
