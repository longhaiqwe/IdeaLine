# 灵感晾台 1.4.1

支持 macOS 14+、Apple Silicon 和 Intel。正式 ZIP 安装包使用 Developer ID 签名并通过 Apple 公证。下载 `IdeaLine-v1.4.1-macOS-universal.zip`，解压后将「灵感晾台.app」放入「应用程序」并打开。

- 手绘风格加入 Looseleaf 官方纸纹，按原始尺寸叠加纸面凹凸、细纤维和明暗变化，覆盖便签、书写窗口、工具栏与选题列表。
- 桌面使用官方灰绿色，默认纸面改为暖米白；绿、蓝、粉红便签调整为更浅的颜色，保留深色文字和清晰纸纹。
- 文字、阴影与主按钮使用独立配色；书写窗口在切换风格时同步更新原生编辑器的文字颜色。
- 纸纹随应用安装，无需额外下载；补齐资源打包及 Looseleaf MIT 授权。

经典纸张风格、选题、草稿、收纳和排序数据保持原有行为。已有用户可在菜单栏点击「检查更新…」升级。

GitHub 自动生成的 Source code 压缩包是源码，直接使用请选择上述应用 ZIP。`SHA256SUMS.txt` 提供安装包的 SHA-256 校验值。
