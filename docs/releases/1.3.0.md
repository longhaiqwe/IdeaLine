# 灵感晾台 1.3.0

支持 macOS 14+、Apple Silicon 和 Intel。正式 ZIP 安装包使用 Developer ID 签名并通过 Apple 公证。下载 `IdeaLine-v1.3.0-macOS-universal.zip`，解压后将「灵感晾台.app」拖入「应用程序」并打开。

- 新增「固定」开关：点击衣杆工具条右侧的图钉，显示「已固定」后保持展开，鼠标移开也不会自动收起。
- 固定状态自动保存，重启后恢复；再次点击可恢复自动收起。使用 Control + Option + L 主动收起衣杆时会解除固定。
- 上下左右四个方位均支持固定，左右侧工具条分两行显示。
- 增加柔和的浅色背景，提升便签在不同桌面背景上的可读性。
- 便签增加轻微摆动、展开时的摇摆和拖动后的回摆，并遵循系统「减少动态效果」设置。

已有用户可在菜单栏点击「检查更新…」升级。选题、草稿、收纳和排序继续保存在本机。

GitHub 自动生成的 Source code 压缩包是源码，直接使用请选择上述应用 ZIP。`SHA256SUMS.txt` 提供安装包的 SHA-256 校验值。
