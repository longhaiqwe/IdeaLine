# 灵感晾台 1.4.0

支持 macOS 14+、Apple Silicon 和 Intel。正式 ZIP 安装包使用 Developer ID 签名并通过 Apple 公证。下载 `IdeaLine-v1.4.0-macOS-universal.zip`，解压后将「灵感晾台.app」拖入「应用程序」并打开。

- 新增「手绘纸张」风格：参考 Looseleaf 的视觉设计，使用略不规则的深色描边、纯色纸面和偏移阴影，覆盖衣杆便签、书写窗口与全部选题页。
- 菜单栏 → 界面风格，可在「经典纸张」和「手绘纸张」之间切换；即时生效，重启后保留选择。
- 四种便签颜色适配新风格。风格偏好独立保存，不改变选题、草稿、收纳与排序。
- 修正书写窗口和恢复操作中固定写为「顶部衣杆」的提示，与四个方位的实际行为保持一致。

已有用户可在菜单栏点击「检查更新…」升级。选题与草稿继续保存在本机。

GitHub 自动生成的 Source code 压缩包是源码，直接使用请选择上述应用 ZIP。`SHA256SUMS.txt` 提供安装包的 SHA-256 校验值。
